# Reference aircraft: Sopwith Camel F.1 (1917). Figures quoted from memory of published specs, all approx:
#   top speed ~113 mph = ~50 m/s (at altitude); gross weight ~1450 lb = ~660 kg; wing area ~231 sq ft = ~21.5 m^2
#   wing loading ~6.3 lb/sq ft = ~31 kg/m^2; climb to 10000 ft in ~10 min (~5 m/s average).
# No glide ratio, stall speed, roll rate or fuel figure is quoted: none is known with confidence, so they are tuning.
#
# Pure game-feel tuning (not derived from the Camel): everything else, notably accel, throttleRate, levelPower,
# glideRatio, liftDamping, controlSpeed, pitchRate, rollRate, yawRate, taxiTurnRadius, taxiMaxTurnRate,
# stallDropRate, stallAuthority, stallPitchFloor, maxTurnRate, maxPitch, maxRoll, levelRate, the landing limits and
# fuelCapacity. maxSpeed (60) is deliberately above the Camel's ~50 m/s so full-throttle dives have headroom;
# stallSpeed, liftoffSpeed and gravity (9.81, physical) are chosen for a short arcade takeoff run.
