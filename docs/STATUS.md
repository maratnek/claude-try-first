  разлёт; агенты это оценить не могут.

## Что готово в игре (`dev`)

- Полёт: взлёт, мощность, сопротивление, сваливание, планирование, координированные
  повороты, руддер A/D (плоский разворот 22°/с), посадка мягкая/жёсткая со
  смягчёнными порогами и скрытой подстройкой.
- Уровень 1: чекпоинты-кольца (считаются только при пролёте сквозь отверстие),
  сосны вместо красных шаров, ворота, зона посадки, экран результатов с
  медалью и лучшим временем (теперь сохраняется); финиш требует взлёта.
- Предупреждения высоты: крупная надпись над землёй, звуковой сигнал, тень по высоте.
- Эффекты: мягкие спрайты для дыма, огня, снега; Low-пресет — тот же мир с
  меньшей детализацией.
- Краш: разлёт v2, взрыв по топливу, дым.
- Платформы: desktop, Web (страница для телефонов, zip для itch.io из CI),
  iOS-симулятор в CI.
- CI: сборка, безоконные тесты, **autoplay** (сценарий настоящей игры на
  Linux с проверками старта, взлёта и поворотов), **web smoke** в Chromium.
