## Что готово в игре (`dev`)

- Полёт: взлёт с разбега, мощность двигателя, сваливание, планирование,
  координированные повороты, руддер A/D плоским поворотом, посадка с
  мягкими лимитами и скрытой помощью, предупреждение высоты над землёй.
- Уровень 1: контрольные кольца (вертикальные, считаются при пролёте),
  жёсткие препятствия — сосны 16 м, ворота, посадка, экран результатов.
- Краш: разлёт v2, огненный шар и дым мягкими спрайтами, снег мягкими
  хлопьями.
- Мир: цветной рельеф, деревья, облака, дождь, снег; пресеты Low/Medium/High
  (Low — тот же мир, меньше деталей).
- Платформы: desktop (macOS), Web и zip для itch.io из CI, заготовка iOS.
- Тесты: безоконные `FlightTests`, `BreakupTests`, `ProgressTests`,
  `LevelDefTests`, `TouchLayoutTests` в CI.
